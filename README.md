# College Algebra Educational Games

Browser games for practicing College Algebra skills. They run on phones and computers, with nothing to install and no account needed.

**Play here:** https://jlgagnon-glitch.github.io/College-Algebra-Educational-Games/

## Games

| Game | Section | Skills |
|---|---|---|
| [Branch & Box](https://jlgagnon-glitch.github.io/College-Algebra-Educational-Games/games/branch-and-box.html) | 1.5 Factoring | Prime factorization, LCM and GCF, GCF of a polynomial, trinomials with a = 1, factoring by grouping (ac method), difference of squares and perfect square trinomials |
| [Over & Out](https://jlgagnon-glitch.github.io/College-Algebra-Educational-Games/games/over-and-out.html) | 1.6 Rational Expressions | Simplifying with restrictions, multiplying and dividing, adding and subtracting with an LCD, complex fractions, common cancelling mistakes |

### Branch & Box

There are six stations, one for each skill in Section 1.5. Each station has five randomly generated rounds. A round with no mistakes earns three stars, and each mistake costs one. Station 6 is a 60-second timed round. Stars are saved in the player's own browser only.

### Over & Out

Factors appear as tiles above and below the fraction bar. Players cancel a factor on top with the same factor on the bottom. Opposite factors such as (7 − x) and (x − 7) do not cancel until −1 is factored out. There are five stations with five randomly generated rounds each, scored the same way as Branch & Box. Station 5 is a 60-second timed round.

## Repository layout

- `index.html` is the landing page that lists every game.
- `games/` holds the games. Each one is a single, self-contained HTML file.
